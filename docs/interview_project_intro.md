**[公司名]** &nbsp;&nbsp;&nbsp;&nbsp; **[起止时间]** &nbsp;&nbsp;&nbsp;&nbsp; **[职位：后端开发]**

**项目名称**：eSIM NL2SQL 数据智能体平台（后端系统）

· **项目描述**：负责企业级数据分析 Web 后端的设计、开发与交付：以 FastAPI 构建 RESTful 服务层，MySQL 8.0 + ChromaDB 双存储，为上层 AI 查询能力提供稳定、安全、可观测、可水平扩展的后端底座。重点解决五类后端工程问题——多租户数据隔离（RLS + 列级脱敏）、高并发下的外部依赖韧性（抖动退避/自动重连/双后端缓存）、SQL 执行安全（fail-closed 四层网关）、数据库性能（索引优化 + EXPLAIN 调优）、交付可观测（监控/审计/K8s 部署），最终交付可部署、可监控、可故障恢复、可水平扩展的后端服务。

· **核心技术栈**：依托后端服务层（FastAPI、RESTful API、JWT 认证、SQLAlchemy ORM、Pydantic 校验、异步 I/O），数据存储层（MySQL 8.0 表设计与索引优化、ChromaDB 向量库、**Redis 查询缓存双后端【memory/redis/auto，故障降级 fail-soft】**、SQL 执行超时与行数限制），安全与多租户（fail-closed 四层 SQL 安全网关【sqlglot AST + 正则兜底】、RLS 行级租户隔离、角色级列脱敏、JWT 权限模型），性能与韧性（Full Jitter 抖动退避、自动重连、重试决策矩阵、故障注入演练），部署与可观测（**Kubernetes 清单【Deployment/ConfigMap/Secret/PVC/三探针】**、Prometheus + Grafana、审计日志、Docker Compose、pytest 327 项自动化测试、语义化版本管理）。

· **核心成果**：
1. **后端架构与性能韧性**：FastAPI 异步服务 + MySQL/向量库双存储分层；**Redis 查询缓存双后端**（memory/redis/auto，Redis 故障自动降级内存，多副本共享一致）；针对高并发下 LLM 调用抖动，落地"指数退避 + 全抖动"重试（实测 100 个并发失败请求重试峰值从 100 降至 3）与自动重连，并做故障注入演练（断连自动恢复、API 故障快速失败）；
2. **数据库性能调优**：EXPLAIN 审计发现 `users.phone_number` 全表扫描，补建高基数索引后查询从 type=ALL（50 行）降至 type=ref（1 行）；联合索引遵循最左前缀并验证 ORDER BY 场景避免 filesort，形成可复现的索引优化流程（`docs/db_index_optimization.md`）；
3. **安全与多租户隔离**：在 SQL 执行边界构建 fail-closed 四层安全网关（解析失败默认拦截）+ RLS 行级租户隔离（sqlglot AST 注入）+ 角色级列脱敏，75 个 SQL/Prompt 注入攻防用例验证（含修复注释拆分绕过的真实漏洞），327 项 pytest 全链路守护；
4. **可观测与工程化交付**：Prometheus/Grafana 监控（QPS、P95 延迟、安全拦截率、纠错率）+ 审计日志 + **Kubernetes 部署清单（多副本 + 三探针 + 配置密钥分离 + PVC 持久化）** + Docker Compose + 语义化版本管理（v0.1-v0.9.0），并自建 54 题评估集与多轮重复评估体系（--trials，均值±标准差），让"回归-验收-迭代"成为标准流程。

· **核心技术栈**：依托大模型与 RAG 应用层（DeepSeek-V3 大模型 API 集成与调用、RAG 检索增强生成【文档解析与语义分块 / all-MiniLM-L6-v2 向量化 / ChromaDB 向量数据库 / 自研混合检索排序】、Agent 编排与工具调用【Vanna 2.0 + 自研 Mini Agent】），结合后端开发（FastAPI、RESTful API、JWT 认证、SQLAlchemy），数据层（MySQL 8.0、ChromaDB 向量库、查询缓存），前端与体验（原生 SPA、Plotly 可视化、示例问题入口、错误反馈提示），质量与迭代（54 题评估集、多轮重复评估、自我纠错回路、Prometheus 监控指标）。

3. **完成 AI 应用产品化交付**：从需求分析到上线全流程独立完成——多轮对话、SQL 执行与可视化图表、角色权限（管理员/分析师/查看者）、错误友好提示（安全拦截/查询失败分级展示）、监控看板，形成可演示、可评估、可迭代的完整产品。
