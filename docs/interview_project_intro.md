**[公司名]** &nbsp;&nbsp;&nbsp;&nbsp; **[起止时间]** &nbsp;&nbsp;&nbsp;&nbsp; **[职位：LLM/Agent 应用开发]**

**项目名称**：eSIM NL2SQL 数据智能体平台

· **项目描述**：负责 eSIM 通信业务数据分析智能体平台的设计与实现。以 Vanna 2.0 Agent + DeepSeek-V3 构建"自然语言 → SQL → 可视化"全链路查询，围绕多租户生产环境的高可用性目标，设计覆盖 LLM 调用、查询执行、平台层的分层韧性体系，并以故障注入演练验证可靠性，交付可部署、可监控、可故障恢复的企业级平台。

· **核心技术栈**：依托 AI/LLM 人工智能层（Vanna 2.0 Agent 编排、DeepSeek-V3、RAG 检索增强生成、9 类错误分类自愈回路），后端服务层（FastAPI、RESTful API、JWT 认证、SQLAlchemy），数据存储层（MySQL 8.0、ChromaDB 向量库、内存查询缓存），安全防护层（fail-closed 四层 SQL 安全网关、RLS 行级租户隔离、角色级列脱敏），可观测与交付层（Prometheus + Grafana 监控告警、审计日志、Docker Compose、pytest 269 项自动化测试）。

· **核心成果**：
1. 构建覆盖"LLM 调用—查询执行—平台层"的高可用体系，并以**故障注入演练**驱动验证：模拟 LLM 断连自动重连成功、模拟 API 故障零无效重试快速失败，显著降低 LLM 服务抖动对线上查询的影响；
2. 查询执行容错：超时与行数控制 + 查询缓存 + 错误分类自愈回路，实测 15% 的题首轮失败后自动修复，执行准确率兜底至 100%，将"首轮失败"转化为"最终成功"；
3. 安全与可观测：fail-closed 四层 SQL 安全网关 + RLS 行级租户隔离 + 角色级列脱敏，75 个注入攻防用例 + 269 项 pytest 守护；Prometheus/Grafana 监控 + 审计日志 + Docker Compose 部署，故障可发现、可定位、可恢复。
